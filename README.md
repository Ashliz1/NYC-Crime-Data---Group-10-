# Group 10 – Crime Analysis Across New York  
## Identifying the Safest County and Time of Day  
CIS 9650 – Term Project (Fall 2025)


## 1. Project Overview
This project examines crime patterns across New York State using the SpotCrime dataset. The objective is to identify:
1. Which county in New York is the safest based on reported crime incidents, and  
2. Which time of day has the lowest crime activity across the state.

Using Python, we cleaned the dataset, engineered time-based features, and produced visualizations to analyze spatial and temporal crime trends. Based on the results, Seneca County was identified as the safest county, and 9 AM was identified as the safest time of day according to the dataset.
